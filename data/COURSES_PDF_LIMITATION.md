# Limitation extraction PDF (7 cours)

Les PDF suivants sont surtout **images / polices non extractibles** : le texte automatique ne contient pas le cours en français lisible.

- Acidose métabolique  
- Alcalose métabolique  
- Hypernatrémie  
- Hyponatrémie  
- Hypocalcémie  
- Hyperphosphatémie  
- Hypophosphatémie  

**Banque QCM actuelle (stricte cours)** : uniquement **Hyperkaliémie**, **Hypokaliémie** et **Hypercalcémie** (causes médicamenteuses extraites).

Pour ajouter les 7 autres cours **sans inventer** :

1. Exporter les slides en **PDF avec texte** ou fournir **Word / PPT texte**.  
2. Placer le texte dans `data/course_text/Nom_du_cours.md`.  
3. Compléter `scripts/curated_banks.py` (ou nous redemander une mise à jour).  
4. Lancer `scripts\run_generate.bat`.
